# Supply Chain SQL Analysis

## Project Overview

This project uses SQL to analyze inventory and supply-chain performance across 180 records. The analysis supports decisions related to demand, replenishment, supplier delivery, lead time, purchase cost, and warehouse stockout risk.

## Business Questions

- Which products have the highest demand?
- Which products are below their reorder point?
- Which suppliers have the best on-time delivery performance?
- Which warehouses have the highest stockout risk?
- Which suppliers have higher lead times, costs, and late deliveries?
- What is the monthly demand trend?

## SQL Skills Demonstrated

- SELECT and filtering with WHERE
- Sorting with ORDER BY
- Aggregation with SUM, AVG, and COUNT
- GROUP BY and HAVING
- CASE WHEN classifications
- Common Table Expressions
- Date analysis with strftime
- Business KPI analysis

## Dataset

The dataset contains 180 supply-chain records with product, category, supplier, warehouse, demand, inventory, reorder point, order quantity, lead time, supplier delivery status, stockout days, holding cost, and purchase cost.

Table name:

\`supply_chain_inventory_data1\`

Important imported column:

\`closing_inventor\`

## Key Analysis Areas

1. Demand by product
2. Inventory below reorder point
3. Supplier on-time performance
4. Stockout risk by warehouse
5. Supplier cost and lead time
6. Monthly demand trend
7. Warehouse risk classification
